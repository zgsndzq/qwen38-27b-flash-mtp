# mem — 记忆目录

把图片（png / jpg / webp）或文本（md / txt）放进这个目录，客户端会把它当作**记忆**：

| `llmchat.bat` 里的 `LLAMA_CHAT_MEM` | 行为 |
|---|---|
| `0` | 不注入（默认） |
| `1` | 首轮注入这里全部**文本** |
| `2` | 首轮注入这里全部**图片**（需要服务端带 `--mmproj`） |
| `3` | 文本 + 图片 |

目录为空时不注入任何东西。**换记忆 = 换这里的文件。**

> 记忆只在**第一轮**注入；在对话里输入 `clear` 可以重新注入。
>
> 内容会进每一次首轮请求的上下文，图多会吃掉上下文预算（一张图约 1024 token）。
>
> 这个目录里的东西**不会**进 git —— 换个人的电脑就该换个人的记忆。
